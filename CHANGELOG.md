# Changelog

## v0.1.0 — 2026-09-02

- Added deterministic task-to-symbol discovery for Go repositories.
- Added root-bound CLI and MCP tools for discovery, slicing, and context packets.
- Added CLI help and compatibility aliases for `intent/query` and `limit/top-k`.
- Added repository manifest and context-content hashes.
- Added a frozen-suite benchmark runner and historical qualification receipts.
- Moved the Model2Vec/bbolt prototype out of the v0.1 core release and preserved
  it on the `experimental/vector` branch.
- Replaced unqualified performance and footprint claims with bounded evidence.
